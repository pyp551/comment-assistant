保存方式

API 与作品网址输入完成后自动保存；其他设置仍使用保存按钮。保存后若正在监听，继续使用原配置；停止监听并等发送收尾后，再点击“应用已保存配置”。

配置保存到 settings.json；评论及发送回执保存在 comments.sqlite3；模型用量保存在 usage.sqlite3；登录状态在 edge-profile 文件夹。密钥选择记住时加密保存，不记住则退出后清除。请备份整个数据目录。

先停止监听再预约，随后退出软件并重新打开。复制评论与去重记录，原目录保留；浏览器登录状态不迁移，新目录需重新登录。目标必须为空。

评论及回执数据库持续保存在本机，用于防止重复发送。关闭窗口不会清空记录，后台服务继续运行；完全退出请点击左下角“退出软件”。此版本不导入任何其他软件的密钥、账号或历史。

看得见的运行规则

可编辑的是模型、提示词和回复设置。以下发送保护不能在界面关闭，以免把“未知”误当作“没发过”。源码完整提供，可在下方查看。

  • 完整正文、作者、唯一行和评论编号匹配后发送；上下文不完整先待查。
  • 已确认及人工回复不重复；未知发送保留记录，不自动重发。
  • 发送串行，至少间隔5秒；最多3份预备草稿，模型并发2。
  • 单条定位预算8秒；失败60至600秒退避；独立发现每30秒，历史补查每120秒。
  • 回执核实最多35秒；健康检查通过后可按配置冻结未知；连续第三次未知停止。
  • 验证码、平台限制、目标改变和手动停止优先停止；不绕过平台验证。
  • 输出最长40字；JSON、去重和讨论串规则由本地代码再次校验。
