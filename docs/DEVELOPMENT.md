# 架构与维护

本机 FastAPI 提供界面与令牌校验接口；Playwright 驱动专用 Edge，读取页面正常返回的数据，不使用私有接口主动批量请求。模型输出只作为语言材料处理，不赋予工具权限。

保存与生效分离。自动保存仅覆盖 API 和视频字段，其他未保存编辑不应被自动提交。运行中不切换模型与作品。修改这些路径须验证并发输入、保存失败和发送收尾条件。

发送串行，发送前预留记录，收到唯一正向回执后确认；未知保留。不要修改未知为成功，不要清预留绕过启动保护。历史读取失败可以局部退避，但不得把未读完当已核查。

发布流程：隔离环境运行全部 unittest；检查前端交互；打包；用空密钥启动验证；只上传源码、文档和明确选择的发行文件。不得 git add 实际用户数据目录。

已知限制：模型可能跳过，完整讨论串和历史深页仍可能定位失败；账号响应结构变化需更新识别器。UI源码查看器不提供在线任意修改执行。
